## 1. GIỚI THIỆU GÓI DỊCH VỤ

Doanh nghiệp của bạn đang cần dữ liệu thị trường, danh mục hàng hóa, bảng giá đối thủ cạnh tranh, danh sách khách hàng tiềm năng B2B nhưng việc copy-paste thủ công tốn hàng chục giờ nhân sự và dễ sai sót?

**Hermes B2B Data Scraper** cung cấp giải pháp cào và chuẩn hóa dữ liệu tự động từ mọi website:
- **Tốc độ xử lý siêu tốc:** Thu thập từ 10.000 đến 100.000+ sản phẩm/bản ghi chỉ trong vài phút.
- **Dữ liệu chuẩn hóa (Cleaned & Structured):** Loại bỏ trùng lặp, tách trường thông minh (tên, mã SKU, giá niêm yết, tình trạng kho hàng, đánh giá, link ảnh, thời gian thu thập).
- **Xuất đa định dạng sẵn sàng sử dụng:** Bàn giao đồng thời file **Microsoft Excel (.xlsx)** được kẻ bảng và định dạng chuyên nghiệp, cùng file **CSV (UTF-8 BOM)** mở trực tiếp trên Excel không bao giờ bị lỗi font tiếng Việt.
- **Vượt rào cản kỹ thuật:** Tích hợp cơ chế tự động xoay vòng User-Agent, chống bị khóa IP, xử lý phân trang vô hạn và tải dữ liệu ngầm an toàn.

## 3. CAM KẾT CHẤT LƯỢNG DỊCH VỤ (SLA)

1. **Cam kết thời gian (24h Delivery):** Bàn giao toàn bộ dữ liệu hoàn chỉnh trong vòng **24 giờ** kể từ thời điểm chốt yêu cầu và duyệt dữ liệu mẫu.
2. **Cam kết chuẩn hóa 100%:** 
   - Không bị trùng lặp dữ liệu (Deduplicated).
   - Dữ liệu số (giá cả, số lượng tồn) được làm sạch thành định dạng số học để phục vụ tính toán, phân tích ngay trên Excel.
   - Định dạng bảng mã `UTF-8 with BOM` đảm bảo mở trên mọi phiên bản Excel (Windows & macOS) hiển thị tiếng Việt hoàn hảo, tuyệt đối không bị lỗi font chữ.
3. **Bảo hành dữ liệu 7 ngày:** Hỗ trợ cào bù hoặc cập nhật miễn phí trong vòng 7 ngày nếu website nguồn cập nhật thêm dữ liệu mới hoặc phát hiện bất kỳ trường thông tin nào bị thiếu sót.

## 4. HƯỚNG DẪN KHÁCH HÀNG NGHIỆM THU DỮ LIỆU (4 BƯỚC NHANH)

Khi nhận bàn giao file kết quả, Quý khách chỉ cần thực hiện 4 bước nghiệm thu đơn giản:

```
┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐     ┌──────────────────┐
│  BƯỚC 1:         │     │  BƯỚC 2:         │     │  BƯỚC 3:         │     │  BƯỚC 4:         │
│  Mở File         │────>│  Kiểm Tra Cột    │────>│  Đối Chiếu Nguồn │────>│  Chốt Nghiệm Thu  │
├──────────────────┤     ├──────────────────┤     ├──────────────────┤     ├──────────────────┤
│ Mở sample.xlsx   │     │ Đủ các trường    │     │ Chọn ngẫu nhiên  │     │ Xác nhận đủ số   │
│ hoặc .csv trên   │     │ thông tin theo   │     │ 5 sản phẩm check │     │ lượng và hoàn    │
│ Excel xem font   │     │ thỏa thuận ban   │     │ link thực tế     │     │ tất thanh toán   │
│ hiển thị chuẩn   │     │ đầu              │     │                  │     │                  │
└──────────────────┘     └──────────────────┘     └──────────────────┘     └──────────────────┘
```

1. **Bước 1 — Kiểm tra hiển thị & font chữ:** Mở trực tiếp file `.xlsx` hoặc `.csv`. Xác nhận tiêu đề bảng rõ ràng, dấu tiếng Việt hiển thị sắc nét, các cột số tiền hiển thị dấu phân cách hàng nghìn rõ ràng.
2. **Bước 2 — Kiểm tra cấu trúc cột:** Xác nhận có đủ các trường thông tin đã yêu cầu (Tên sản phẩm, Mã định danh, Giá, Tình trạng hàng, Đánh giá, Link sản phẩm, Ảnh, Thời gian cào).
3. **Bước 3 — Đối chiếu ngẫu nhiên (Spot-check):** Bấm vào 3–5 link sản phẩm chi tiết trong file để đối chiếu thông tin trên file với thực tế trên website gốc (đảm bảo khớp giá và tên 100%).
4. **Bước 4 — Xác nhận số lượng:** Kiểm tra tổng số dòng dữ liệu khớp với cam kết trong báo giá.

## 5. HƯỚNG DẪN KỸ THUẬT & TỰ CHẠY SCRIPT (DÀNH CHO ĐỘI NGŨ NỘI BỘ / IT)

Gói phần mềm đi kèm mã nguồn Python hoàn chỉnh và môi trường ảo đóng gói sẵn:

### Cấu trúc gói sản phẩm:
```
outputs/monetization/packages/b2b_data_scraper/
├── .venv/                     # Môi trường ảo Python độc lập (đã cài đủ thư viện)
├── scraper.py                 # Mã nguồn crawler chính (Retry logic, Multi-format exporter)
├── requirements.txt           # Danh sách thư viện phụ thuộc (requests, bs4, openpyxl)
├── sample_output.csv          # Dữ liệu mẫu đã cào thành công (UTF-8 BOM)
├── sample_output.xlsx         # Bảng tính Excel mẫu định dạng chuyên nghiệp
└── README.md                  # Tài liệu giới thiệu dịch vụ & hướng dẫn nghiệm thu
```

### Lệnh chạy nhanh:
```bash
# 1. Chạy với môi trường ảo có sẵn trong gói:
./.venv/bin/python scraper.py --pages 3

# 2. Hoặc cài đặt độc lập trên máy mới:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scraper.py --pages 5 --csv output.csv --excel output.xlsx
```

### Các tham số tùy biến (CLI Arguments):
- `--pages N`: Số trang danh mục cần cào (Mặc định: 3 trang).
- `--csv <path>`: Tên và đường dẫn file CSV xuất ra.
- `--excel <path>`: Tên và đường dẫn file Excel xuất ra.
- `--delay <sec>`: Thời gian nghỉ giữa các lượt cào (chống quá tải server).
